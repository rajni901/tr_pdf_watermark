How to Use

1

Configure in Settings

  • Go to Settings → PDF Watermark
  • Tick the documents you want watermarked
  • Enter the watermark text (e.g. DRAFT)
  • Set color using hex code (e.g. #cc0000 for red)
  • Click Save
2

Print Any Document

Open any Invoice, Sale Order or Purchase Order → click Print → the watermark appears automatically on every page of the PDF.

3

Color Presets

  • Light Grey: #cccccc
  • Red: #cc0000
  • Blue: #0000cc
  • Green: #006600
  • Orange: #cc6600
